# Конфигурация эксперимента надёжности

- ОС: Windows, локальный адрес `127.0.0.1`.
- Язык: Go 1.24, только стандартная библиотека.
- В каждой серии: 5 прогревочных PING/PONG и 50 надёжных команд SHOOT.
- Максимум попыток: 4; начальный RTO: 1000 мс; границы RTO: 100–3000 мс.
- Seed генератора джиттера: 42.
- Потери воспроизводимы: сервер отбрасывает только первую доставку каждого 20-го, 10-го или 5-го sequence.
- `baseline`: без потерь и задержек.
- `loss_5`, `loss_10`, `loss_20`: 5%, 10%, 20% первых отправок теряются.
- `delay_100_loss_5`: задержка ответа 100 мс и потеря 5% первых отправок.
- `jitter_loss_10`: задержка ответа равномерно 50–150 мс и потеря 10% первых отправок.

Повтор запускается теми же командами из README. Сырые данные сохраняются в `docs/reliability_samples.csv`, отчёт и SVG строит `cmd/reliability-report`.
